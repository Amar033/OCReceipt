# 📄 OCR Invoice Processor (Single File Streamlit App)

A lightweight, single-file Streamlit app to extract key information from invoice images using **Tesseract OCR** and **pattern matching**.

---

## 🚀 Features

- Extracts text from invoice images
- Parses:
  - Invoice Number
  - Invoice Date
  - Due Date
  - Total Amount
  - Supplier/Company Name
  - Phone Number
- Detects line items (description, quantity, price, total)
- Provides OCR confidence analysis
- Allows export of extracted data as JSON
- Image preprocessing for improved OCR accuracy
